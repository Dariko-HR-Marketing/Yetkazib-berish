# Suhbat va pilot rejasi

Maqsad: kod yozishdan oldin uchta eng xavfli farazni tekshirish — (1) do'kon egasi oylik paket uchun to'laydimi, (2) o'z kuryeri bormi yoki platforma kuryeri kerakmi, (3) xaridor Telegram orqali do'kondan buyurtma beradimi.

## 1. Do'kon egalari bilan suhbat (8 ta, 30 daqiqa)

Kim: Toshkentdagi 3 ta mahalla do'koni, 2 ta minimarket, 1 ta dorixona, 1 ta gul do'koni, 1 ta 2–3 filialli tarmoq. Prototip ekranlari: Owner-Plan, Owner-Delivery, Owner-Money.

| # | Savol |
| --- | --- |
| D-1 | Hozir buyurtmani qanday qabul qilasiz (telefon, Telegram, agregator)? Kuniga nechta? |
| D-2 | Oxirgi marta buyurtma yo'qolgan yoki kechikkan holatni aytib bering. Nima bo'ldi? |
| D-3 | Yetkazishni kim qiladi? Kuryerga qancha to'laysiz? Naqd pulni qanday hisoblaysiz? |
| D-4 | Qoldiqni qayerda yuritasiz (Billz, 1C, daftar)? |
| D-5 | Doimiy xaridorlaringizni bilasizmi? Ularga qanday murojaat qilasiz? |
| D-6 | (Owner-Plan ekrani) Qaysi paketni tanlaysiz? Qaysi narxda “qimmat” deysiz? |
| D-7 | Agregatorda ishlaysizmi? Komissiya qancha? Nima yoqmaydi? |
| D-8 | (Owner-Delivery ekrani) O'z kuryeringiz band bo'lsa, 12 000 so'mga platforma kuryeri kerakmi? |
| D-9 | Ertaga ishga tushsa, birinchi oy bepul pilotga qo'shilasizmi? Kim ishlatadi? |

Qoida: kelajak haqida emas, o'tgan voqealar haqida so'raymiz; narxni ekranni ko'rsatgandan keyin so'raymiz.

## 2. Xaridorlar (10 ta, 15 daqiqa) va kuryerlar (5 ta, 20 daqiqa)

- Xaridor: oxirgi onlayn xaridi; nega agregator yoki do'kon; Telegram mini-ilovani (Shop-Marketplace) sinab ko'rish — vazifa: “sut va non buyurtma qiling”; ball tushunarlimi.
- Kuryer: hozir qayerda ishlaydi, kunlik daromad, naqd bilan muammolar, Android telefon modeli (GPS ilovasi uchun), o'zini o'zi band maqomi bormi.

## 3. Pilot (S8 dan keyin, 8 hafta)

| Parametr | Qiymat |
| --- | --- |
| Hudud | Toshkent: Chilonzor va Yunusobod |
| Do'konlar | 20 ta (Start va Biznes, birinchi oy bepul) |
| Kanallar | Veb + Telegram mini-ilova; o'z kuryeri + Yandex Dostavka. Platforma kuryerlari puli o'chiq |
| To'lov | Payme, Click, Uzum; naqd — faqat o'z kuryeri bilan |

## 4. Muvaffaqiyat mezonlari (8-hafta oxirida)

| Mezon | Maqsad | Agar bajarilmasa |
| --- | --- | --- |
| Faol do'konlar (haftada ≥ 20 buyurtma) | ≥ 12 / 20 | Onboarding va sotuv yondashuvini qayta ko'rish |
| Pullik paketga o'tish (1-oydan keyin) | ≥ 40% | Narx yoki paket tarkibini o'zgartirish |
| Xaridorning 30 kunlik qayta xaridi | ≥ 35% | Sodiqlik va eslatmalarni kuchaytirish |
| Vaqtida yetkazish | ≥ 90% | Kuryer kanallari va zonalar |
| Qoldiq xatosi (“tugadi” keyin) | ≤ 3% buyurtma | POS integratsiyani oldinga surish |
| Do'kon NPS | ≥ 40 | Suhbat orqali sabab topish |

Natija bo'yicha qaror: kengayish (boshqa tumanlar), o'zgartirish (narx, paket) yoki to'xtatib qayta ko'rib chiqish.
